## Установка как PWA (на телефон)

Приложение — прогрессивное веб-приложение (PWA), можно добавить на главный экран.

### Android (Chrome)
1. Откройте http://195.209.215.182:3000
2. Войдите и попользуйтесь сайтом.
3. Меню **⋮** → **«Установить приложение»** (или «Добавить на главный экран»).
4. Подтвердите. Иконка появится на домашнем экране, откроется как отдельное окно.

### iPhone / iPad (Safari)
1. Откройте сайт в Safari.
2. **«Поделиться»** (квадрат со стрелкой вверх).
3. **«На главный экран»** → **«Добавить»**.

### Основные команды на VPS

```bash
ssh -i privatekey-1123009.pem ubuntu@195.209.215.182

cd ~/Hello-STATUS
docker compose ps          # статус контейнеров
docker compose logs -f next-app   # логи приложения
docker compose up -d --build      # пересобрать и запустить
docker compose restart next-app   # перезапустить приложение
```

> Переменные окружения (`NEXTAUTH_SECRET`, `NEXTAUTH_URL`) заданы в `~/Hello-STATUS/.env` на сервере.
